# Stress Detection using HRV Parameters

This project detects stress using Heart Rate Variability (HRV) features extracted from ECG signals.

## Technologies Used
- Python
- NeuroKit2
- NumPy
- Pandas
- Matplotlib

## Features
- ECG signal preprocessing
- R-peak detection
- HRV feature extraction
- Stress analysis

## Dataset
MIT-BIH Arrhythmia Dataset

## Output
HRV Time Domain, Frequency Domain, and Nonlinear parameters.
